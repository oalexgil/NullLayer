# Policy Review Checklist

Use this checklist before relying on any NullLayer-generated draft.

## Organization and scope

- [ ] Controller/organization identity is correct.
- [ ] Website/app/product scope is correct.
- [ ] Target jurisdictions have been confirmed.
- [ ] Privacy contact channel is correct and monitored.

## Data map

- [ ] Every personal-data category in the policy is actually collected.
- [ ] No collected category is missing from the policy.
- [ ] Processing purposes match real product behavior.
- [ ] Sensitive/special-category data is handled explicitly if applicable.
- [ ] Children/minors handling is accurate if applicable.

## Legal review

- [ ] Legal bases were determined by an appropriate reviewer; they were not inferred by the model.
- [ ] Jurisdiction-specific rights language is current and applicable.
- [ ] Regulator/supervisory-authority language is appropriate.
- [ ] DPO/representative statements are correct where relevant.
- [ ] Automated decision-making/profiling statements are accurate.

## Vendors and transfers

- [ ] Every named processor/vendor is actually used.
- [ ] Data shared with each vendor is accurately described.
- [ ] Payment, analytics, advertising and AI providers are current.
- [ ] International-transfer statements match real vendor/contracts/data flows.

## Retention and deletion

- [ ] Retention periods or deletion criteria are verified.
- [ ] Product deletion behavior matches the policy.
- [ ] Legal/contractual retention exceptions are reviewed where needed.

## Security

- [ ] Security statements describe controls that actually exist.
- [ ] No absolute guarantee of security is made.
- [ ] Encryption/MFA/access-control claims have been verified.

## Output hygiene

- [ ] No `[REVIEW REQUIRED: ...]` placeholder remains unresolved.
- [ ] No invented article number, law, vendor or retention period appears.
- [ ] No API key, credential or internal secret is present.
- [ ] Dates/version/contact details are current.
- [ ] The final policy has received appropriate privacy/legal review.

Passing this checklist is a workflow control, not a legal compliance certification.
